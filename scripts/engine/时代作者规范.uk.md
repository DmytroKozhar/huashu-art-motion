# Авторські вимоги до епох (малювання лише кодом)

Український переклад [оригіналу](时代作者规范.md) зі знімка `64cb27271ee0ad3375298e2890b33cbec36d4051`. Приклади команд збережено; це документація, а не повідомлення про виконання цих команд.

> Це авторські вимоги до відтворення ролика зі швидким оглядом історії мистецтва. Наведені нижче координати композиції й образи персонажів стосуються лише цього ролика та подібних швидких оглядів або подорожей крізь епохи. Загальну версію див. у `references/08-风格作者规范.md` від кореня пакета; для нової теми потрібно заново побудувати відповідну їй композицію.

Кожна епоха, за яку ви відповідаєте, — окремий файл `scenes/<id>.js`. Реєстрація:

```js
SCENES['<id>'] = { draw(c, lt, t) { /* 画满 1920x1080 */ } };
```

Коментар у прикладі: заповніть малюнком усе полотно 1920×1080.

- `c` — цільовий 2D-контекст; `lt` — локальний час цього фрагмента в секундах, від початку переходу до цієї епохи (може трохи перевищувати тривалість фрагмента); `t` — час усього відео.
- **Не малюйте табличку з роком**: її малює рушій у верхньому правому куті, у межах 1500–1890 × 40–210. Залиште тут тло й не розміщуйте важливих елементів.
- **Не змінюйте `lib/`, `engine.js`, `eras.js`, `transitions.js` або файли сцен інших авторів**. Потрібні допоміжні функції пишіть у власному файлі.

## Доступні бібліотеки (спочатку прочитайте вихідний код)

- `lib/paint.js` → `PAINT`: шум noise/fbm; текстури texture/grain/craquelure; рукотворні лінії roughPath/boilSeed; стильові рендерери strokes (мазки за полем потоку, із підтримкою регіональних палітр palette)/dabs/mosaic/halftone/pixelate/facets; набори кольорів `swatch`; спільна хореографія `choreo`; steam; particles; позаекранне полотно `scratch(key)`.
- `lib/rig.js` → `RIG`: `RIG.girl(opt)` — скелет дівчини, що сидить боком ліворуч (повертає Path2D частин тіла та опорні точки `G.A`); `RIG.drawGirl(c,G,pal)` (pal.mode може бути fill/line); `RIG.cat(opt)` — скелет рудо-білого кота, що сидить праворуч; `RIG.drawCat(c,K,pal)`; `RIG.drawCup`; `RIG.smooth(points)` — плавні криві; `RIG.taper` — кінцівки зі звуженням; `RIG.ik2`.
- **Еталонна реалізація: `scenes/09_postimp.js` (Ван Гог)**. Розгляньте її структуру: підмальовок пласкими кольорами → перемальовування стильовим рендерером (регіональні палітри) → пласкі кольори персонажів і дрібні мазки → домальовування контурів → рухомі відблиски.

## Обов’язкові вимоги

1. **Спільний каркас сцени**. Стандартна композиція: вікно (350,120)–(810,560), кіт на підлозі (390,610)–(690,905), стіл (810,620)–(1200,905), людина (1120,200)–(1500,910). У вихідному ролику всі епохи вирівняно за цими позиціями; переходи також від них залежать.
2. **Персонажі**. Людина — 17-річна європейська білява дівчина в **дівочому вбранні відповідної епохи** (вбрання скромне). Кіт — **рудо-білий**: верх голови, спина й хвіст руді зі смужками, мордочка, груди, живіт і лапи білі.
   Обов’язково використовуйте скелети й хореографію `RIG.girl` / `RIG.cat` (ті самі скелети й рухи), але змінюйте спосіб малювання відповідно до епохи. Можна брати лише Path2D та самостійно робити заливку, контури чи силует, додавати одяг до опорних точок або стилізувати точки скелета під епоху (наприклад, фронтальне око в єгипетському стилі чи чорнофігурний силует).
3. **Усе зображене має оживати**. Рухи головних персонажів задавайте через `PAINT.choreo(lt,t)`: піднімання чашки cup, помах хвостом tail, кліпання blink, дихання breathe.
   Додайте ще 2–4 **короткі цикли з візуальних мотивів відповідної епохи**. Перелік див. у розділах про рух усередині плану для кожної епохи у `../拆解/分镜表.md`: наприклад, біг наскельних тварин через чергування двох поз, скарабей, що котить сонячну кулю, рух меандрової стрічки, дим Везувію, ковзання відблиску по сусальному золоту, політ орнітоптера, падіння пелюсток сакури, мерехтіння світлових плям тощо.
   Кожна епоха залишається на екрані лише 0,25–1,4 секунди; рух має бути **помітним** у цьому проміжку.
4. **Стиль створюється кодом**. Рендерери, текстури й лінії мають перетворити зображення на мистецький твір відповідної епохи, а не на кліпарт. Для відчуття ручного малюнка можна додати «кипіння» ліній (boilSeed) із частотою 8–12 кадрів/с.
5. **Продуктивність**. Кожен кадр — не довше 150 мс за 1920×1080. Статичні частини кешуйте через `PAINT.cached`. Уся випадковість має використовувати seed: однакове t повинно давати однаковий кадр.

## Референси

- Кадр відповідної епохи з референсного відео: `../生图/ref/<id>.png` (композиція, мотиви, кольори та все, крім лічильника; кадри потрібно самостійно витягнути з референсного відео, вони не поширюються зі skill).
- Створені ШІ концепт-арти: `../生图/plates/<id>.png` — та сама композиція, персонажів уже замінено на біляву дівчину й рудо-білого кота. Використовуйте як художні референси; **вставляти зображення у відео заборонено**, малюйте лише кодом.
- Рух усередині плану й вихідні точки переходів: `../拆解/分镜表.md`.
- Референсне відео 60 кадрів/с: `../原片/<参考片>.mp4` (надаєте самостійно).

## Самоперевірка (щонайменше 3 раунди для кожної епохи)

```sh
cd <你的项目目录>   # 里面有 代码工程/（从 scripts/engine 复制）
uv run --with playwright python 代码工程/render.py --solo <id> --stills 0,0.3,0.6,0.9 --out 渲染/<id>
uv run --with playwright python 代码工程/render.py --solo <id> --from 0 --to 1.2 --out 渲染/<id>/clip.mp4
```

Перейдіть до свого каталогу проєкту; він має містити 代码工程/, скопійований із scripts/engine.

За допомогою PIL зберіть поруч свої кадри, кадри оригіналу й концепт-арти. Запитайте себе: ① Чи можна відразу впізнати епоху або художника? ② Чи схожа дівчина на 17-річну біляву дівчину, а кіт — рудо-білий? ③ Чи видно рух зображення протягом однієї секунди? ④ Чи немає візуальних збоїв: зміщень, обірваних ліній, неправильного перекриття або порожніх місць?

Якщо хоча б один пункт не пройдено, виправляйте, доки результат не стане задовільним.

# Сумісність і межі перевірки

Український переклад [оригіналу](compatibility.md) зі знімка `64cb27271ee0ad3375298e2890b33cbec36d4051`. Наведені результати й дата перевірок належать авторові вихідного проєкту; під час перекладу ці тести не запускалися.

Дата перевірки: 2026-10-08. Нижче окремо розглянуто встановлення й конфігурацію, виконання хостом в онлайн-сеансі та фактичну генерацію медіа. Успішна перевірка одного рівня не замінює перевірок інших.

## Встановлення й оновлення конфігурації

В ізольованій робочій копії Git офіційним CLI skills фактично виконано `skills add <本地发布包> --skill huashu-art-motion --agent <宿主> --yes --copy`; для кожного цільового хоста встановлення проведено двічі поспіль. Для claude-code, codex і kimi-code-cli обидва встановлення були успішними, а media.json поза каталогом встановлення залишився побайтово незмінним. Тут перевірено збереження вподобань після повторного встановлення із заміною файлів; це не означає повної симуляції всіх історичних версій чи реалізацій update усіх інсталяторів.

Стара конфігурація голосу об’єднується з новими типовими полями без переписування. Нова можливість роботи із зображеннями залишається невибраною й недозволеною. CLI встановленої копії для Codex прочитав попереднє налаштування system і revision, не повернувши їх до спільних значень за замовчуванням.

## Онлайн-виконання на хостах

- Codex CLI 0.160.1: реальний сеанс завантажив встановлений skill і настанови; перевірено стан без конфігурації, заборону генерації, відсутність інструментів, імпорт наявного зображення та збереження особистого налаштування system. Вихідне зображення побайтово збіглося з джерелом; джерела конфігурації відповідали очікуваним.
- Claude Code 2.1.287: встановлення й локальний CLI працюють; онлайн-сеанс повернув 429 через тижневу квоту поточного тестового середовища, тому регресійну перевірку виконання моделлю не завершено. Це не дає підстав ані позначати онлайн-перевірку успішною, ані вважати Skill несумісним.
- Kimi Code CLI 0.38.0: встановлення й локальний CLI працюють; онлайн-сеанс повернув 403 через права доступу поточного тестового облікового запису, тому регресійну перевірку виконання моделлю не завершено. У цій версії неінтерактивний `--prompt` не можна поєднувати з `--auto` чи `--yolo`; після виправлення команди повторна спроба все одно повернула 403 облікового запису.

Ці сеанси використовували ізольовані робочі каталоги й конфігурації медіа та вже наявні локальні входи, а не три нові облікові записи. Після відновлення доступу облікових записів Claude/Kimi онлайн-сценарії ще потрібно виконати. Можливості інструментів залежать від конкретного сеансу; назва хоста не гарантує наявності генерації зображень.

## Реальні медіарезультати й автоматичні тести

Системний голос macOS і клонування голосу Volcengine (火山) успішно згенерували справжні короткі фрази. Поточний сеанс Codex фактично викликав вбудовану генерацію зображень, отримав PNG 1536×1024 із прозорими пікселями та пройшов шлях plan → виклик інструмента → квитанція → копіювання до проєкту й перевірка SHA. Інструмент зображень викликав агент; CLI не виконував цей виклик замість нього. Тест підтверджує лише шлях інтеграції та властивості файлу, а не художню якість.

Автоматичні тести охоплюють об’єднання конфігурацій, посилення обмежень дозволів, конкурентні записи, старий вихідний формат PCM, незавершені потоки мовлення, вибір властивостей зображень і типу оплати, плани між сеансами, відкликання налаштувань, конкурентну заміну зображень та перевірки об’єктів випуску. CI працює на Linux; справжній системний голос перевірено лише на macOS, системні голосові бекенди Windows/Linux ще не реалізовані.

## Мінімальні відтворювані перевірки

```sh
python scripts/capabilities.py status --config <一个空JSON文件> --explain
python scripts/capabilities.py image-status --config <禁止生图的JSON> --mode generate
python scripts/capabilities.py use-image --file <现有PNG> --out <项目>/配图/新文件.png
python -m unittest discover -s tests -v
```

Для перевірки реального інструмента зображень створіть знімок поточної схеми інструментів за [настановами щодо зображень](images.uk.md). Якщо інструмента немає, явно поверніть unavailable; не імітуйте успіх вигаданим інструментом. CI без облікових даних чи дозволу не викликає платні медіасервіси.

# Стан українського перекладу

[Український README](README.uk.md) · [Оригінал](README.md)

Базова версія: `64cb27271ee0ad3375298e2890b33cbec36d4051`.

Перший етап: повний український README із додатковим поясненням архітектури, запуску й обмежень; переклад усіх 15 основних розділів SKILL; мовна навігація в оригінальних документах. Оригінальні документи та ліцензії збережено.

Переклад коментарів і додаткових посібників триває в цій самій гілці. Це не повна локалізація репозиторію. Початкова статична інвентаризація знайшла 5 145 коментарів із китайськими ієрогліфами: 241 Python, 4 902 JavaScript та 2 HTML. Окремо виявлено 67 Python docstring із такими символами; вони залишаються без змін, оскільки є рядками програми. Детальний звіт буде додано після інтеграції перекладів.

Усі 313 отриманих текстових файлів звірено з Git blob SHA вихідного дерева. 127 бінарних файлів не завантажувалися й не змінюються; віддалені коміти будуються поверх повного вихідного дерева, тому медіафайли зберігаються. Код і тести проєкту не запускалися, залежності не встановлювалися, генерація та платні сервіси не використовувалися.
